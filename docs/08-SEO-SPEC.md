# EygülTurizm — SEO Specification

## 1. Goal

Site arama motorları için anlaşılır, hızlı ve semantic olmalıdır.

## 2. Title

Title gerçek marka ve hizmeti açıklamalıdır.

Örnek yapı:

```text
EygülTurizm | Personel ve Okul Servis Taşımacılığı
```

Gerçek hizmet kapsamına göre kullanıcı tarafından güncellenmelidir.

## 3. Meta description

Yaklaşık 140–160 karakter hedeflenebilir.

Gerçek olmayan iddialar eklenmemelidir.

## 4. Canonical

Production domain belli olduğunda canonical eklenmelidir.

## 5. Open Graph

Desteklenmelidir:

```text
og:title
og:description
og:image
og:url
og:type
```

## 6. Social image

1200×630 sosyal paylaşım görseli önerilir.

## 7. Structured data

Gerçek bilgiler sağlandıysa uygun schema kullanılabilir.

Örneğin:

```text
LocalBusiness
Organization
Service
```

Uydurma adres, telefon veya rating eklenmemelidir.

## 8. Sitemap

Production domain belirlendiğinde sitemap oluşturulmalıdır.

## 9. Robots

Production ortamında robots.txt bulunmalıdır.

## 10. Semantic sections

Ana bölümler semantic section/article yapısında olmalıdır.

## 11. Image SEO

Alt text gerçek görseli tanımlamalıdır.

Keyword stuffing yapılmamalıdır.

## 12. SEO acceptance

- [ ] Title.
- [ ] Meta description.
- [ ] Canonical.
- [ ] OG tags.
- [ ] Semantic headings.
- [ ] Sitemap.
- [ ] Robots.
- [ ] Structured data where appropriate.
