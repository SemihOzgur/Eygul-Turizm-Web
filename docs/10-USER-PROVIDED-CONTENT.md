# EygülTurizm — User Provided Content Checklist

Bu dosya proje başlamadan önce EygülTurizm tarafından sağlanması gereken gerçek içeriklerin ana listesidir.

## 1. Şirket bilgileri

Lütfen aşağıdakileri sağlayın:

```text
Şirketin tam resmi adı:
Marka adı:
Kısa marka adı:
Slogan varsa:
Kuruluş yılı:
Kısa şirket tanımı:
```

Kuruluş yılı gibi bilgiler yalnızca gerçekten doğrulanabiliyorsa verilmelidir.

## 2. İletişim

```text

```

```text

```

## 7. Hizmetler

Her hizmet için:

```text
Hizmet adı:
Kısa açıklama:
Detaylı açıklama:

```

Mevcut hizmetler:

```text

```

Ek hizmet varsa ayrıca belirtilmelidir.

## 8. Filo

Her araç için:

```text
Marka:
Model:
Model yılı:
Kapasite:
Konfor özellikleri:
Güvenlik özellikleri:
Araç görseli:
Kullanım alanı:
```

Özellikle kapasite, model yılı ve güvenlik özellikleri doğrulanmalıdır.

## 9. Güven / başarı verileri

Varsa:

```text
Toplam araç sayısı:
Toplam personel:
Hizmet verilen kurum sayısı:
Yıllık taşınan kişi:
Faaliyet yılı:
Zamanında varış oranı:
Müşteri memnuniyet oranı:
```

Her yüzdelik veya sayı doğrulanabilir olmalıdır.

Örneğin `%99.8 zamanında varış` bilgisi şirket tarafından doğrulanmadıysa siteye eklenmemelidir.

## 10. Sertifikalar

Varsa:

```text

```

Belge görselleri mümkünse yüksek çözünürlükte verilmelidir.

## 11. Müşteri / referans logoları

Kullanılmasına izin verilen kurumlar:


## 20. İçerik teslim formatı

En kolay yöntem:

```text
company.md
services.md
fleet.md
hero-scenes.md
legal.md
```

dosyalarıyla teslim etmektir.

Alternatif olarak tek bir `content.json` kullanılabilir.

## 21. Minimum launch package

Siteyi başlatmak için minimum:

- [ ] Logo
- [ ] Telefon
- [ ] WhatsApp
- [ ] E-mail
- [ ] Şirket kısa açıklaması
- [ ] Hizmet listesi
- [ ] Filo listesi
- [ ] Hero video
- [ ] Hero poster
- [ ] Hero scene metinleri
- [ ] En az bir iletişim CTA'sı
- [ ] Domain (deploy aşamasında)

## 22. Eksik bilgi kuralı

Bilgi verilmediyse AI:

- bilgi uydurmamalı
- sahte istatistik üretmemeli
- sahte sertifika yazmamalı
- sahte müşteri logosu koymamalı
- sahte adres/telefon koymamalı

Bunun yerine açık placeholder kullanmalıdır:

```text
[TELEFON EKLENECEK]
[WHATSAPP NUMARASI EKLENECEK]
[ŞİRKET AÇIKLAMASI EKLENECEK]
```
